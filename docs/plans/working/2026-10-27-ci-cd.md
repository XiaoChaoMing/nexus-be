## 1. Task Brief

- **Mục tiêu:**
  - Mỗi PR / push trên 3 repo có **một check bắt buộc** (`ci-ok`) xanh trong < 15 phút (backend) / < 6 phút (web, admin), phủ
    đủ: lint, test `-race` có Postgres / Redis thật, migration `up → down → up`, Swagger không lệch, `govulncheck`, lint
    Dockerfile / compose / workflow, build mọi image.
  - E2E Playwright của web (18 test) và admin (8 test) chạy tự động trên stack compose đầy đủ (provider `fake`, Mailpit, ffmpeg)
    hằng đêm và theo yêu cầu, có trace / video / log làm artifact.
  - Tag `vX.Y.Z` phát hành image lên GHCR (`ghcr.io/xiaochaoming/nexus-*`) + release notes.
  - Bản demo cập nhật bằng **một workflow** (hoặc một lệnh), có backup trước khi deploy, smoke test sau deploy và rollback về tag
    trước — thay tunnel cloudflared bằng domain thật cho IPN SePay.
- **Trong phạm vi:** WP0–WP9 ở §3.
- **Ngoài phạm vi:** Kubernetes / Helm / Terraform; zero-downtime (blue-green, rolling); autoscaling; CDN riêng cho HLS; SePay
  production; email thật qua SMTP nhà cung cấp; nhiều máy chủ; OIDC tới cloud provider; gộp 3 repo thành monorepo (CI-Q15).
- **Giả định:**
  - Không thêm module Go, gói npm hay service mới. Công cụ đã có trong `go.mod` (`go tool golangci-lint`, `swag`,
    `govulncheck`) được dùng thay cho Action tương ứng khi có thể.
  - Image Docker mới (Caddy, hadolint, gitleaks, actionlint) và **mọi Action mới** chỉ thêm sau khi duyệt ở CI-Q4 (Prohibition 1
    của `AGENTS.md`).
  - Secret chỉ nằm trong GitHub Secrets / Environments và `.env` trên máy chủ (chmod 600); không có secret nào trong repo, log
    hay plan.
  - Phiên bản Go lấy từ `go.mod` (1.27), Node 22, pnpm 10 như hiện tại.
- **Câu hỏi mở:** §12. Hai câu chặn công việc nhiều nhất: **CI-Q1** (đích deploy + domain) và **CI-Q2** (repo public hay private —
  quyết định số phút Actions và kích cỡ runner).

  (`CHANNEL_PG_POOL_MAX`, `CHANNEL_S3_USE_SSL`, `CHANNEL_S3_ENSURE_BUCKET`, `CHANNEL_MEDIA_BASE`, …, `CHANNEL_REMINDER_LEAD`);
  stream **`STREAM_END_COOLDOWN`**, `STREAM_VOD_EXPIRY_TICK`, `STREAM_SCHEDULE_TICK`; chat 13 biến (`CHAT_WS_*`,
  `CHAT_RATE_LIMIT_PRIVILEGED`, `CHAT_MAX_LINES`, `CHAT_HISTORY_ON_JOIN`, `CHAT_RETENTION`, `CHAT_PARTITION_TICK`,

- Giá trị **cứng** trong compose cần tham số hóa trước khi deploy: mật khẩu Postgres (`x-db-environment`, `db-init`,

  với danh sách ngoại lệ có chú thích (biến chỉ dùng khi chạy service ngoài Docker, ví dụ `*_JWKS_URL` trỏ `localhost`).
- **Tham số hóa giá trị cứng:** `POSTGRES_PASSWORD`, `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD`, user / pass NATS, Grafana admin,

  Postgres trong compose dựng từ `${NXL_PG_PASSWORD_URLENC}` (mật khẩu đã mã hóa URL; ghi rõ trong `.env.example`).
- **`image:` cho mọi service build từ repo:** `image: ${NXL_IMAGE_REGISTRY:-nexuslive}/nexus-<svc>:${NXL_IMAGE_TAG:-dev}` cạnh

- **Edge sau proxy:** `set_real_ip_from` (dải mạng Docker của compose + IP proxy), `real_ip_header X-Forwarded-For`,

### WP1 — CI backend

- **Matrix sinh tự động:** job `setup` đọc `go work edit -json | jq -c '[.Use[].DiskPath]'` (jq có sẵn trên runner) → output
  `modules`; danh sách service có Dockerfile từ `ls services/*/Dockerfile`; danh sách service có migration từ
  `services/*/migrations`. Bước kiểm: `NXL_GO_MODULES` trong Makefile phải bằng `go.work` (lệch → fail, nhắc sửa Makefile). Cập
  nhật `AGENTS.md` (mục "Adding a service module" bỏ "and to the module matrix").
- **`changes`:** job nhỏ chạy `git diff --name-only` so với base để biết có đổi Go / migration / Docker / compose / chỉ docs; các
  job nặng `if:` theo đó. **Không** dùng `paths-ignore` ở mức workflow (check bắt buộc sẽ treo "pending" trên PR chỉ sửa docs).
- **Lint:** `go -C <module> tool golangci-lint run ./...` (đúng bản trong `go.mod`, như `make nxl-lint`), cache
  `~/.cache/golangci-lint` + Go build cache; bỏ `golangci-lint-action` và biến `GOLANGCI_LINT_VERSION`. Thêm một job `fmt`:
  `make format` rồi `git diff --exit-code`.
- **Test:** giữ `-race -covermode atomic`; thay 7 bước copy-paste bằng `scripts/ci/prepare-db.sh <svc>` (chạy
  `deploy/postgres/init-databases.sql` một lần rồi `migrate up` cho DB của module); Postgres / Redis chỉ khởi động cho module cần
  (2 matrix include: `with-db` / `no-db`, hoặc job riêng cho `.` và `media`). Xuất `coverage.out` thành artifact (không dịch vụ
  coverage bên ngoài).
- **Migration:** job `migrations` — mọi service có `migrations/`: kiểm từng `.up.sql` có `.down.sql` cùng tên, chạy `up → down
  -all → up` bằng `migrate/migrate:v4.18.3` (image đã dùng), so `pg_dump --schema-only` lần 1 và lần 2 phải giống nhau.
- **Swagger:** job `swagger` (khi đổi Go): `make nxl-swag && git diff --exit-code -- services/*/docs` (đúng image
  `golang:1.27-alpine3.23` của Makefile; media không có Swagger).
- **Bảo mật dependency:** `go mod verify` (root) + `make deps-audit` (`go tool govulncheck` mọi module) — trên PR khi đổi
  `go.mod` / `go.sum`, và hằng đêm (WP3). Lỗ hổng có bản vá → fail; không có bản vá → cảnh báo (`continue-on-error` cho bước
  đêm, ghi lý do).
- **Compose / edge / workflow:** `docker compose --profile nxl --profile obs config -q` (cả với `deploy/compose.demo.yml` của WP7);
  `nginx -t` trong `nginx:1.31.3-alpine` với template đã render bằng `envsubst` theo `.env.example` (edge dùng `resolver
  127.0.0.11` và biến cho upstream nên `-t` không cần DNS — xác nhận khi làm); `actionlint` (image `rhysd/actionlint`, CI-Q4);
  `env-contract.sh` của WP0.
- **Dockerfile:** hadolint chạy bằng image `hadolint/hadolint` (bỏ `reviewdog/action-hadolint`) hoặc giữ reviewdog nhưng cấp
  `pull-requests: write` cho đúng job (CI-Q4). Tương tự yamllint (`yamllint` cài bằng `pipx`, có sẵn trên runner) và
  dotenv-linter.
- **Image:** một job matrix 8 service, `docker/setup-buildx-action` + `docker/build-push-action` với `cache-from/to:
  type=gha,scope=<svc>`; trên PR chỉ build (`push: false`, `load: false`), trên `main` / tag push sang GHCR (WP5). Dockerfile thêm
  `RUN --mount=type=cache,target=/root/.cache/go-build` + `/go/pkg/mod`, `ARG TARGETOS TARGETARCH` thay `GOARCH=amd64` cứng
  (cần nếu VPS là ARM), giữ thứ tự `COPY` (go.work bắt buộc có mọi service).
- **Chung:** `concurrency: { group: ${{ github.workflow }}-${{ github.ref }}, cancel-in-progress: ${{ github.event_name ==
  'pull_request' }} }`; `timeout-minutes` mỗi job (lint 15, test 20, image 20); `actions/setup-go` dùng `go-version-file: go.mod`;
  `permissions: {}` ở đầu, mỗi job xin đúng quyền cần.
- **Check tổng `ci-ok`:** job cuối `needs:` mọi job, `if: always()`, fail nếu có job `failure` / `cancelled` (job `skipped` vì
  `changes` là hợp lệ). Đây là check bắt buộc duy nhất (WP3) — tên ổn định dù matrix đổi.

### WP3 — Chuỗi cung ứng, secret, branch protection

- **Quét secret:** bật **secret scanning + push protection** của GitHub (miễn phí với repo public; private cần GitHub Advanced

  7. **Rollback** (`deploy.sh --rollback` hoặc `deploy.sh <tag-trước>`): kéo image tag trước, `up -d`; **không** chạy `migrate
     down` tự động. Nếu release có migration phá vỡ (không được phép theo `AGENTS.md`), khôi phục từ backup theo runbook.
- **Workflow `deploy.yml`** (backend): `workflow_dispatch` (input `tag`, `rollback: boolean`) + tùy chọn tự chạy khi `release:

## 8. Rủi ro

| Rủi ro | Giảm thiểu |
| --- | --- |
| Lần chạy CI đầu tiên lộ hàng loạt lỗi (YAML, quyền, `go.sum`, Dockerfile chưa từng build trên Linux CI) | Bước 2 push trước khi sửa, gom lỗi vào WP1; sửa lỗi build là Lightweight track |
| Repo private hết 2.000 phút / tháng | Job `changes`, `concurrency`, gộp lint thành ít job hơn nếu cần, E2E chỉ khi có commit; theo dõi Settings → Billing tuần đầu |
| E2E flaky trên runner 2 vCPU (transcode + Chrome) | `superfast`, `retries: 1`, báo flaky riêng; nếu vẫn > 10 % đêm đỏ → chạy E2E trên runner public 4 vCPU (repo public) hoặc chỉ on-demand |
| Thay đổi compose làm vỡ stack dev (giá trị mặc định khác code) | Mặc định `${VAR:-…}` = giá trị hiện tại; `docker compose config` trước / sau so khớp (diff chỉ có `image:` và biến mới); chạy lại `make nxl-up-all` + E2E local |
| Real IP cấu hình sai → rate limit gộp hoặc giả mạo IP | Chỉ tin `X-Forwarded-For` từ IP proxy cố định; smoke kiểm `429` theo IP thật (curl 2 nguồn) |
| Lộ secret (log workflow, `.env` admin, `docker compose config` in giá trị) | gitleaks + push protection; không chạy `docker compose config` không `-q` trên máy chủ trong log CI; secret chỉ trên máy chủ; `set +x` trong script deploy |
| Giá trị dev (khóa payout, HLS secret, mật khẩu DB) bị dùng ở máy demo | `deploy.sh` từ chối chạy khi `.env` còn giá trị dev đã biết (danh sách trong `env-contract.sh`) |
| Migration không đảo được làm rollback thất bại | Job `migrations` (up → down → up) ở mọi PR; quy tắc chỉ-thêm của `AGENTS.md`; backup trước deploy |
| VPS 4 vCPU không đủ transcode 2 luồng + stack ~20 container | `make nxl-bench` ngay khi có VPS; `MEDIA_MAX_CONCURRENT_STREAMS` theo số đo; tắt `obs` / Jaeger nếu thiếu RAM |
| Cloudflare / ISP chặn RTMP, IPN SePay không tới | RTMP DNS-only; IPN thử bằng sandbox ở bước 9; `sync` + reconcile vẫn chạy khi IPN mất (GĐ6) |
| Action / image bên thứ ba bị chiếm quyền | Ghim SHA, digest cho image công cụ, Dependabot bump có review |
| Chủ đồ án mất quyền truy cập máy chủ gần ngày bảo vệ | Phương án A dự phòng + video demo (GĐ8); runbook có bước dựng lại từ đầu bằng tag + backup |

## 13. Tiêu chí hoàn thành

- Given một PR chỉ sửa `docs/`, Then `ci-ok` xanh trong < 2 phút và không job nặng nào chạy.

  / Dockerfile / env-contract, build 8 image. PR web / admin: `ci-ok` xanh < 6 phút.

  Release có notes + digest.
