# Working Plan — Đa ngôn ngữ (i18n) cho nexuslive-web

| Track | Trạng thái | Ngày |
| --- | --- | --- |
| Standard (chỉ `nexuslive-web`; không đổi API) | Approved — đã triển khai | 2026-10-12 |

## 1. Task Brief

- **Mục tiêu:** tách toàn bộ chuỗi giao diện ra file ngôn ngữ để phát triển đa ngôn ngữ; người dùng đổi được Tiếng Việt / English, lựa chọn được ghi nhớ.
- **Trong phạm vi:** khung app, đăng nhập/đăng ký/tài khoản, trang chủ, trang xem live + player, Studio, thông báo lỗi/validation, định dạng ngày giờ/số theo ngôn ngữ, nút đổi ngôn ngữ.
- **Ngoài phạm vi:** trang `/dev/ui` (tham chiếu nội bộ); dịch nội dung do người dùng nhập (tiêu đề, tag); thông báo lỗi trả từ backend (web đã ánh xạ theo mã lỗi); ngôn ngữ RTL.
- **Quyết định (đã hỏi):** thư viện `react-i18next` (+ `i18next`, `i18next-browser-languagedetector`); ngôn ngữ `vi` (mặc định, nguồn) + `en`; làm toàn bộ web; viết plan rồi làm luôn.
- **Giả định:** chuỗi nhúng sẵn trong bundle (nhỏ, khởi tạo đồng bộ, không nháy chữ); ưu tiên lựa chọn đã lưu, sau đó ngôn ngữ trình duyệt.

## 2. Thiết kế

| Phần | Cách làm |
| --- | --- |
| Cấu trúc | `src/locales/{vi,en}/{common,auth,home,watch,player,studio}.json`; `src/i18n/resources.ts` gom tài nguyên; `src/i18n/index.ts` khởi tạo |
| Kiểu key | `src/i18n/i18next.d.ts` lấy kiểu từ bộ `vi` → gõ sai key là lỗi typecheck |
| Phát hiện ngôn ngữ | `localStorage` (`nxl.lang`) → `navigator`; fallback `vi`; cập nhật `<html lang>` |
| Chuỗi ngoài component | zod schema, mã lỗi API, cảnh báo health trả **key** `"ns:path"`; component dịch qua `useMessage()` |
| Định dạng | `src/lib/format.ts` dùng locale theo ngôn ngữ (`vi-VN` / `en-US`) |
| Đổi ngôn ngữ | `LanguageMenu` (icon) ở top bar và trang đăng nhập |
| Bundle | tách chunk `react`, `i18n`, `radix` để chunk chính < 650 kB |
